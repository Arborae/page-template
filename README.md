## Publishing checklist

Before making a new Arborae tool repository public:

- [ ] Replace `<Tool Name>` and `<repo-name>` in `README.md` and `index.html`.
- [ ] Keep the app zero-dependency and single-file when possible (no unnecessary build steps or external trackers).
- [ ] Verify there is no personal data, secret, token, or private address anywhere in the repository.
- [ ] Enable **GitHub Pages** in **Settings → Pages**: deploy from branch `main`, folder `/ (root)`.
- [ ] Add repository topics: **`arborae-page`** (required for automatic indexing on [arborae.github.io](https://arborae.github.io/#tools)) plus one or more category topics (for example `utility`, `converter`, `home-assistant`, `devops`).
- [ ] Optionally set the repository **Website** (`homepage`) field to `https://arborae.github.io/<repo-name>/`.
